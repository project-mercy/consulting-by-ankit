# Ascend Consulting

I want to create a website where I can sell my consulting services to clients around the world. I am skilled in Tech, Business, and Sustainability. The website should contain:

1. Previous Projects
2. A payment page
3. A about me page
4. References from Previous clients.

My website should be clean, aesthetic, and modern. It should work well with mobile and computers.
